# Reported Speech Studio — Apple-Style Grammar Quiz

A soft, Apple-inspired quiz website for mastering **Reported Speech (Direct & Indirect Speech)**, including tricky exam traps.

It is packaged as a **single self-contained HTML file** (`index.html`) with zero external dependencies, so it works 100% offline on any computer.

## Features

- **Soft Apple Cupertino UI**: Frosted glass cards, soft pastel ambient mesh background, squircle badges, smooth transitions, and a manual **Light / Dark Mode** toggle (`☀️` / `🌙`).
- **6 Question Types + Mixed Challenge**:
  - **Type A · Multiple Choice**: Choose the accurate reported sentence.
  - **Type B · True or False**: Spot subtle grammar traps in conversions.
  - **Type C · Fill in the Blank**: Type the exact missing word or phrase.
  - **Type D · Error Spotting**: Identify the flawed segment in the sentence.
  - **Type E · Word & Tense Shifts**: Master backshifts, modals & exceptions.
  - **Type F · Back to Direct**: Reconstruct the speaker's original words.
  - **★ Mixed Challenge**: Random questions across all 6 categories.
- **3 Difficulty Levels**:
  - **Easy**: Foundational tense backshifts and pronoun changes.
  - **Medium**: Wh- & Yes/No questions, imperatives, and time/place shifts.
  - **Hard (Tricky)**: 27–28 deceptive questions per type (160+ Hard questions total) covering Second Conditionals, *wish / would rather / it's high time*, modals of deduction vs. prohibition (*must / mustn't*), *used to / had better*, *forbid / deny* double-negative traps, *suggest / explain* object traps, *confess to / object to + V-ing*, and subject vs. object embedded questions.
- **Flexible Session Length**: Choose **10 Soal**, **20 Soal**, or **All** available questions in the selected pool.
- **⬇ Download HTML Button**: Save a clean standalone copy of the quiz file anytime to run on another computer.
